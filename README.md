# 🖥️ SQL_Learning

A structured T-SQL learning repository documenting my journey through SQL Server concepts — from joins and set operators to window functions and subqueries.

## 📖 About

This repository contains hands-on T-SQL scripts written and practised in **SQL Server Management Studio (SSMS)**. Each folder covers a distinct SQL topic, with scripts demonstrating real query patterns used in data analytics and data engineering.

## 📁 Repository Structure

| Folder | Topics Covered |
|--------|----------------|
| `01-Relational-Joins` | INNER, LEFT, RIGHT, FULL OUTER, CROSS joins and advanced join patterns |
| `02-SET-Operators` | UNION, UNION ALL, INTERSECT, EXCEPT |
| `03-SQL-Functions` | String, numeric, and conversion functions |
| `04-SQL-Stored-Procedures` | Creating, executing, and parameterizing stored procedures |
| `05-DATE-TIME-Functions` | GETDATE, DATEADD, DATEDIFF, FORMAT, and temporal logic |
| `17-Value-Functions` | Window value functions: FIRST_VALUE, LAST_VALUE, LAG, LEAD |
| `18_Subqueries` | Correlated and non-correlated subqueries, EXISTS, IN |
